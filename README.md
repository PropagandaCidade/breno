# BriefingBot 🤖

Agente para criação de briefings profissionais de projetos.

## Como usar

### Opção 1: Template Editável
1. Abra o arquivo `briefing-template.md`
2. Preencha as informações nos campos [ ]
3. Salve com o nome do projeto

### Opção 2: Gerar via Python
Execute `python main.py` e responda as perguntas (não funciona em todos terminais).

### Opção 3: Criar manualmente
Copie o template e crie seu próprio briefing seguindo a estrutura.

## Estrutura do Briefing

1. **Informações Básicas** - Nome, cliente, prazo, orçamento
2. **Descrição** - O que é, objetivos, problema, público
3. **Requisitos** - Funcionalidades, restrições, integrações
4. **Design** - Referências, cores, estilo, concorrentes
5. **Entregáveis** - O que entregar, formato, prioridades
6. **Cronograma** - Marcos e datas importantes

## Local de armazenamento

Os briefings são salvos em:
`C:\Users\Usuario\.voice-hub\briefings\`

## Exemplos de uso

- Novo website
- App mobile
- Campanha de marketing
- Identidade visual
- Automação de bots
- Projeto de áudio/locução
