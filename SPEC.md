# SPEC.md - BriefingBot

## Agente: BriefingBot

**Nome:** BriefingBot  
**Objetivo:** Criar briefings detalhados para projetos de design, desenvolvimento e marketing com base em inputs do usuário.

---

## O que o BriefingBot faz

1. **Coleta informações** do usuário sobre o projeto
2. **Estrutura** um briefing profissional e completo
3. **Gera** documento em Markdown ou HTML
4. **Salva** para referência futura

---

## Estrutura do Briefing

### 1. Informações Básicas
- Nome do projeto
- Cliente/Titular
- Data de criação
- Prazo
- Orçamento (se aplicável)

### 2. Descrição do Projeto
- O que é o projeto?
- Objetivos principais
- Problema a resolver
- Público-alvo

### 3. Requisitos
- Funcionalidades necessárias
- Restrições técnicas
- Integrações necessárias

### 4. Design
- Referências visuais
- Cores preferidas
- Estilo desejado
- Concorrentes/Reference

### 5. Entregáveis
- O que deve ser entregue
- Formato (site, app, design, etc)
- Prioridades

### 6. Cronograma
- Marcos principais
- Datas importantes

---

## Tipos de Briefing Suportados

1. **Website** - Landing page, site institucional, e-commerce
2. **App** - Aplicativo mobile ou web
3. **Design** - Identidade visual, branding, UI
4. **Marketing** - Campanha, estratégia
5. **Áudio** - Script para locução, jingle

---

## Fluxo de Uso

1. BriefingBot faz perguntas sobre o projeto
2. Usuário responde
3. BriefingBot gera documento estruturado
4. Salva em arquivo `.md` ou `.html`

---

## Saída

- Arquivo Markdown para fácil edição
- Visualização HTML opcional
- Salvo na pasta do projeto
